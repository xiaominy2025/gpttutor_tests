### Engent Labs — Canonical Development and Deployment Standards

The authoritative engineering standard is maintained at:

[https://github.com/xiaominy2025/gpttutor-frontend/blob/main/docs/ENGENTLABS_DEVELOPMENT_DEPLOYMENT_PLAYBOOK.md](https://github.com/xiaominy2025/gpttutor-frontend/blob/main/docs/ENGENTLABS_DEVELOPMENT_DEPLOYMENT_PLAYBOOK.md)

Before significant design, development, architecture, integration or deployment work, retrieve and review the latest accepted version from the default branch.

Apply the relevant standards for the application's established Type A, B or C integration pattern.

The latest accepted playbook supersedes conflicting historical Engent Labs guidance.

Individual Coach teams own product development, testing and Alpha deployment. Homepage/Platform owns shared integration and coordinated Production publication. The Best Practices chat maintains standards only.

Apply the 80/20 principle. Reuse proven architecture, test what changed, diagnose before altering, respect standing owner authorization and escalate only material deviations.

Do not introduce additional discretionary approval gates. Respect mandatory execution-tool security approvals.

If the canonical playbook cannot be retrieved, report the limitation rather than silently relying on obsolete guidance.
